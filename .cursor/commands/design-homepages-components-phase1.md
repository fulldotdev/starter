# Marketing homepages - Components phase 1

Create FIVE unique homepage drafts in `src/pages/1.astro` through `src/pages/5.astro`.

## Goal

Build strong structure and UX using components-first implementation. This is phase 1 only; SOS polish happens later.

## Rules

- Scope is only `src/pages/1.astro` to `src/pages/5.astro`.
- Use `src/components/ui` primitives strictly as the primary building blocks.
- Use `Layout`, `LayoutHead`, `LayoutBody`, and `LayoutMain` on each page.
- Use `NavigationMenu` for primary nav, plus other relevant primitives (buttons, cards, list, image, input/textarea, accordion, etc.) where they fit naturally.
- Prefer component variants/composition over long per-instance class strings.
- Keep Tailwind token utilities (`bg-background`, `text-foreground`, `border-border`, etc.) for layout/theme consistency.
- Do not do "sauce pass" polish in this phase (no heavy decorative CSS, no complex motion scripting).

Use your frontend design skill to make these phase-1 drafts excellent and clearly distinct.
