## What is Fulldev Starter?

Fulldev Starter is a template designed to kickstart your project using the fulldev-ui library and markdown. It's built to supercharge content-driven website development with Astro, allowing you to easily use blocks from fulldev-ui to build pages and content-driven websites.

### Key Features

1. **Content-Layer Integration**: Fulldev Starter provides a robust content layer, making it easy to manage and structure your website's content. You can find detailed documentation on how to work with the content layer in the [fulldev-ui docs](https://ui.full.dev/overview/content-layer).

2. **Pre-built Components**: The template comes with various components such as blocks, layouts, and UI elements, primarily sourced from the FullUI Library. These pre-built, customizable elements can be used directly in your pages.

3. **Customization Options**: You have the flexibility to customize any component by creating a component with the same name in the corresponding directory (`src/blocks/`, `src/layouts/`, `src/components/`, etc.) to override the FullUI version.

4. **Theming and Styling**: Fulldev Starter uses a custom integration for theming. You can easily change the theme by following the [customization guide](https://ui.full.dev/overview/customization).

5. **Template Updates**: For experienced developers, the README provides instructions on how to fetch and merge the latest changes from the template repository.

Fulldev Starter is designed to streamline your development process, allowing you to focus on creating content-rich, visually appealing websites with ease. Whether you're building a simple blog or a complex content-driven platform, Fulldev Starter provides the tools and structure you need to get started quickly and efficiently.
