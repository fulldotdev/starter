## Quick Start Guide

The Fulldev Starter Template provides a solid foundation for your next project. Here's how to get started:

1. **Fork and Clone**: Fork the repository and clone it to your local machine.
2. **Install Dependencies**: Run `pnpm install` to set up the project.
3. **Start Developing**: Use `pnpm dev` to launch the development server.
4. **Explore the Structure**: Familiarize yourself with the `src/content/pages` directory.

With these simple steps, you'll be ready to start building your site using the power of Fulldev UI and markdown!
